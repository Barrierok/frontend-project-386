# Triage-метки

Скиллы говорят о пяти канонических triage-ролях. Этот файл сопоставляет роли с реальными строками меток в трекере этого репозитория.

| Роль в mattpocock/skills | Метка в нашем трекере | Значение                                 |
| ------------------------ | --------------------- | ---------------------------------------- |
| `needs-triage`           | `needs-triage`        | Мейнтейнеру нужно оценить задачу         |
| `needs-info`             | `needs-info`          | Ждём информации от автора                |
| `ready-for-agent`        | `ready-for-agent`     | Полностью описана, готова для AFK-агента |
| `ready-for-human`        | `ready-for-human`     | Требует реализации человеком             |
| `wontfix`                | `wontfix`             | Не будет сделано                         |

Когда скилл упоминает роль (например, «навесь метку AFK-ready»), используйте соответствующую строку метки из этой таблицы.

Если в трекере появится другая терминология, правьте колонку «Метка в нашем трекере».
