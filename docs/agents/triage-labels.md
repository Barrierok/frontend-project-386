# Метки триажа

Навыки говорят на языке пяти канонических ролей триажа. Этот файл сопоставляет роли с реальными строками меток в трекере задач этого репозитория.

| Метка в mattpocock/skills | Метка в нашем трекере | Значение                                      |
| ------------------------- | --------------------- | --------------------------------------------- |
| `needs-triage`            | `needs-triage`        | Мейнтейнеру нужно оценить задачу              |
| `needs-info`              | `needs-info`          | Ожидается информация от автора                |
| `ready-for-agent`         | `ready-for-agent`     | Полностью описана, готова для агента без участия человека |
| `ready-for-human`         | `ready-for-human`     | Требует реализации человеком                  |
| `wontfix`                 | `wontfix`             | Не будет исправлено                           |

Когда навык упоминает роль (например, «навесь метку готовности для агента»), используй соответствующую строку метки из этой таблицы.

Столбец «Метка в нашем трекере» редактируй под тот словарь, который реально используется.
