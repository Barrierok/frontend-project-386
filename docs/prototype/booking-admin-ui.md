# Прототип экранов `/booking` и `/admin`

Одноразовый артефакт для тикета #12. Живёт на ветке `prototype/booking-admin-ui`, в `main` не мержится. Код помечен комментариями «ПРОТОТИП», данные вымышленные, сохранения нет.

## Как открыть

```bash
npm run dev
```

- <http://localhost:3000/prototype> — точка входа.
- <http://localhost:3000/prototype/booking> — запись гостя.
- <http://localhost:3000/prototype/admin> — кабинет владельца.

Внизу экрана — плавающая панель: стрелки (или клавиши `←` / `→`) переключают вариант, чипы — состояние. Текущие значения видны в URL: `?variant=a&scenario=conflict`.

## Варианты `/booking`

| Ключ | Название           | Структура                                                                                                               |
| ---- | ------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| `a`  | Недельная сетка    | Две недели табами, дни колонками, свободные старты кнопками. Липкая панель справа: выбранный слот и форма.              |
| `b`  | Пошаговый список   | Мастер из трёх шагов. Тип события — радиокнопки, 14 дней — вертикальный список с чипами времени, форма заменяет список. |
| `c`  | Календарь и шторка | Сетка 14 дней (2 ряда по 7), у дня счётчик свободных мест. Время — панель под календарём, форма — в модальной шторке.   |

Состояния (`scenario`): `default`, `empty-types`, `empty-slots`, `conflict`, `success`.

## Варианты `/admin`

| Ключ | Название          | Структура                                                                                 |
| ---- | ----------------- | ----------------------------------------------------------------------------------------- |
| `a`  | Форма и таблица   | Форма создания в левой колонке, предстоящие записи — таблицей справа.                     |
| `b`  | Панель и таймлайн | Компактная строка создания сверху, типы событий карточками, записи сгруппированы по дням. |
| `c`  | Мастер-деталь     | Типы событий списком слева (фильтр ленты), записи справа, создание — в модальном окне.    |

Состояния (`scenario`): `default`, `empty-types`, `empty-bookings`.

## Что прототип не решает

Поведение по шагам (что происходит при 409, двойной отправке, валидации) фиксируется в тикете #13. Здесь показан один из возможных вариантов: при конфликте слот сбрасывается, имя и email сохраняются, показывается сообщение «Это время уже занято, выберите другой слот».
